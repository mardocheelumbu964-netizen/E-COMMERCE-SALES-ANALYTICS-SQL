# E-COMMERCE SALES & CUSTOMER ANALYTICS

Complete MySQL portfolio project covering customers, products, categories, orders, payments, shipping, discounts, reviews and advanced sales analytics.

## SQL Skills
DDL/DML, constraints, JOINs, aggregations, subqueries, CTEs, CASE, window functions, views, stored procedures, triggers, indexes and business KPI analysis.

## How to Run
Use MySQL 8.0+.
Run:
1. database/01_create_database.sql
2. database/02_create_tables.sql
3. database/03_insert_sample_data.sql

Then run the files in queries, views, procedures, triggers and indexes.

## Main Analysis
Revenue, monthly sales, average order value, top customers, product performance, category performance, customer segmentation, repeat customers, payment methods, delivery delays, discounts and profit estimates.
